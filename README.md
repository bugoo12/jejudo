## 🤖 환석 AI 교육 준비물

### VS Code
1. [code.visualstudio.com](https://code.visualstudio.com/) 접속 → 다운로드
2. 설치 (Next만 누르면 됨)
3. `Ctrl+Shift+P` → "Configure Display Language" → 한국어
4. Python 확장 설치

### Python
1. [python.org](https://www.python.org/downloads/) 접속 → 다운로드
2. **"Add Python to PATH" 체크** 후 설치
3. 터미널에서 `python --version`으로 확인

### OpenCode
1. [nodejs.org](https://nodejs.org/) 접속 → LTS 설치
2. `npm install -g opencode-ai`
3. `opencode` 실행
4. `/connect` → API 키 입력
