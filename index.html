📝 VS Code 설치

1다운로드: https://code.visualstudio.com/ 접속
2설치: Windows 64-bit 다운로드 후 설치 (Next만 누르면 됨)
3한국어 설정: Ctrl+Shift+P → "Configure Display Language" → 한국어 선택
4필수 확장: Python, Korean Language Pack 설치

🐍 Python 설치

1다운로드: https://www.python.org/downloads/ 접속
2설치: "Add Python to PATH" 체크 후 Install Now
3확인: 터미널에서 python --version 입력
4VS Code 연동: VS Code에서 Python 파일 생성하면 자동 인식

⚡ OpenCode 설치

1Node.js 설치: https://nodejs.org/ 접속 → LTS 버전 설치
2OpenCode 설치: 터미널에서 npm install -g opencode-ai
3실행: 프로젝트 폴더에서 opencode 입력
4AI 연결: /connect → API 키 입력 (또는 무료 모델 사용)
